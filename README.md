# Portafolio

Sitio web personal hecho con HTML, CSS y JavaScript (sin dependencias).

## Cómo verlo

Abre `index.html` en tu navegador, o usa la extensión **Live Server** de VS Code.

## Estructura

- `index.html` — contenido y secciones (inicio, sobre mí, proyectos, contacto)
- `styles.css` — estilos
- `script.js` — interacciones (año del footer, formulario de contacto)
